/** * Kitsong School of Royal Bafokeng * Matric Gratitude Dinner — RSVP Handler * * Sheet column layout (MUST match this exact order): * A = Timestamp * B = Learner Name * C = Parent Phone * D = Ticket Count * E = Transportation * F = Total Amount * G = Payment Method * H = Event * I = Event Date * J = Venue */ const SHEET_NAME = 'Sheet1'; // ← change if your tab is named differently const NAME_COLUMN = 2; // column B = learner name (for duplicate check) const DATA_START_ROW = 2; // row 1 = headers /** * Handles form POST requests */ function doPost(e) { try { const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME); if (!sheet) { return jsonResponse({ status: 'error', message: 'Sheet not found: ' + SHEET_NAME }); } const data = e.parameter || {}; // ---------- Extract & sanitize every field ---------- const learnerName = cleanName(data.learnerName); const parentPhone = cleanName(data.parentPhone); const ticketCount = cleanName(data.ticketCount); const transportation = cleanName(data.transportation); const totalAmount = cleanName(data.totalAmount); const paymentMethod = cleanName(data.paymentMethod) || 'Cash at Admin Reception'; const eventName = cleanName(data.event) || 'Matric Gratitude Dinner'; const eventDate = cleanName(data.eventDate) || '9 October 2026'; const venue = cleanName(data.venue) || 'Rain Hill Farm'; // ---------- Validation ---------- if (!learnerName) { return jsonResponse({ status: 'error', message: 'Learner name is required.' }); } if (!parentPhone) { return jsonResponse({ status: 'error', message: 'Parent phone is required.' }); } if (!ticketCount) { return jsonResponse({ status: 'error', message: 'Ticket count is required.' }); } if (!transportation) { return jsonResponse({ status: 'error', message: 'Transportation is required.' }); } // ---------- Server-side total guard (R50 × tickets) ---------- const ticketsNum = parseInt(ticketCount, 10); const expectedTotal = (!isNaN(ticketsNum) && ticketsNum >= 1 && ticketsNum <= 3) ? ticketsNum * 50 : 0; // Prefer the server-computed total (protects against a stale/zero hidden field) const finalTotal = expectedTotal > 0 ? expectedTotal : (parseInt(totalAmount, 10) || 0); // ---------- Duplicate check ---------- if (isDuplicate(sheet, learnerName)) { return jsonResponse({ status: 'duplicate', message: 'This learner has already been RSVP\'d.' }); } // ---------- Append the row (order MUST match columns A-J) ---------- sheet.appendRow([ new Date(), // A - Timestamp learnerName, // B - Learner Name parentPhone, // C - Parent Phone ticketCount, // D - Ticket Count transportation, // E - Transportation finalTotal, // F - Total Amount paymentMethod, // G - Payment Method eventName, // H - Event eventDate, // I - Event Date venue // J - Venue ]); return jsonResponse({ status: 'success', learnerName: learnerName, transportation: transportation, totalAmount: finalTotal }); } catch (err) { return jsonResponse({ status: 'error', message: err.toString() }); } } /** * Handles GET requests (for testing in a browser) */ function doGet(e) { return jsonResponse({ status: 'ok', message: 'Kitsong RSVP endpoint is live.' }); } // ---------- Helpers ---------- function cleanName(val) { return (val == null ? '' : val.toString()).replace(/\s+/g, ' ').trim(); } function isDuplicate(sheet, learnerName) { const lastRow = sheet.getLastRow(); if (lastRow < DATA_START_ROW) return false; const numRows = lastRow - DATA_START_ROW + 1; const names = sheet .getRange(DATA_START_ROW, NAME_COLUMN, numRows, 1) .getValues() .flat() .map(function (n) { return cleanName(n).toLowerCase(); }); return names.indexOf(learnerName.toLowerCase()) !== -1; } function jsonResponse(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } // ---------- MANUAL TEST — run this from the editor to verify ---------- function testAddRow() { const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME); if (!sheet) { Logger.log('❌ Sheet not found: ' + SHEET_NAME); return; } sheet.appendRow([ new Date(), 'TEST LEARNER', '072 000 0000', '2', 'Bus at school', '100', 'Cash at Admin Reception', 'Matric Gratitude Dinner', '9 October 2026', 'Rain Hill Farm' ]); Logger.log('✅ Test row added. Sheet now has ' + sheet.getLastColumn() + ' columns.'); }
